Practice Exam 1: Analytical Methods & GeoComputation

1. Which geoprocessing tool combines geometries and attributes from both layers, keeping only the areas where the features overlap?

Correct: B. Intersect calculates the geometric intersection of any input layers. Features that overlap will be written to the output feature class with attributes from all input layers combined.

2. You are using Inverse Distance Weighting (IDW) for spatial interpolation. What happens to the estimated value as you move further away from a known sample point?

Correct: B. IDW explicitly assumes that closer things are more related than distant things. The weight or influence of a sample point decreases as the distance to the estimated location increases.

Practice Exam 2: Conceptual Foundations & Geodesy

1. Which surface model represents the Earth's shape using a uniform mathematical formula that is flattened at the poles?

Correct: C. A reference ellipsoid is a mathematically smoothed surface generated by rotating an ellipse around its minor axis to approximate an oblate spheroid.

2. What property is preserved when using a Conformal map projection?

Correct: B. Conformal projections preserve local angles and shapes around points, though they can significantly distort area sizes across larger regions.

Practice Exam 3: Data Modeling & Structures

1. You need to connect a table of state polygons to a table containing multiple historic governors for each state. Which table relationship should you use?

Correct: C. Since a single state feature relates to multiple records in the governor table, this is a one-to-many relationship. A table relate or relationship class should be used instead of a standard join.

2. In geospatial vector topology rules, what does the concept of "Adjacency" explicitly track?

Correct: B. Adjacency is the topological property that tracks shared boundaries between neighboring polygon features.

Practice Exam 4: Geospatial Data & Metadata Quality

1. Which core component of metadata tracks the original data sources and processing steps used to create a dataset?

Correct: B. Lineage metadata documents the history of a dataset, including its source materials, transformations, and any geoprocessing steps applied.

2. Which file extension stores the core dBASE attribute table data within a traditional shapefile format structure?

Correct: C. The `.dbf` file format stores the tabular attribute data for features in a shapefile structure.

Practice Exam 5: Cartography & Visualization

1. What cartographic error occurs when raw count totals (such as total infections per state) are mapped directly onto a choropleth layout map without normalization?

Correct: B. Mapping raw counts on a choropleth map can create area-size bias. Larger geographic areas appear artificially prominent simply because of their size, which is why raw counts should be normalized into densities or rates.

2. Which visual variable is the most effective option for displaying qualitative, categorical data layers like soil or land-use types?

Correct: B. Color Hue (different colors like red, green, blue) is ideal for separating distinct qualitative categories without implying that one category is higher or better than another.

Practice Exam 6: Systems Design & Professional Ethics

1. According to the GISCI Code of Ethics, what is a GIS professional's primary duty when a data analysis reveals potential public health or safety risks?

Correct: C. The GISCI Code of Ethics states that a professional's highest duty is to society, which includes speaking up if a project or data finding could negatively impact public safety or welfare.

2. Which type of open geospatial web service allows clients to query and directly edit vector feature geometry over the internet?

Correct: B. An OGC Web Feature Service (WFS) provides access to the underlying vector geometries and attribute fields, allowing users to query, download, or edit features directly.
