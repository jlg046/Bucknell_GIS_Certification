Workshop 1: Geodesy, Datums, and Coordinate Systems

GISCI Alignment: Category 2: Conceptual Foundations (14% Weight)
Software Environment: ArcGIS Pro (3.x)

PART A: TEACHER'S MASTER INSTRUCTION GUIDE

1. Conceptual Whiteboard Script (0:00 - 0:15)

Draw the three-tiered shape approximation of the Earth on the whiteboard:
The Geoid: The actual physical surface of gravitational equal-potential (the irregular "potato" shape).
The Reference Ellipsoid: The mathematically smoothed quadratic surface defined by its semi-major axis (a) and flattening (f).
The Geodetic Datum: Connects the ellipsoid to the physical Earth. Explain the difference between local datums (e.g., NAD27, which match the surface locally) and Earth-centered datums (e.g., WGS84, which align with the Earth's center of mass).

Next, write out the four primary projection distortions: SAPE (Shape / Conformal, Area / Equivalent, Persistence of Scale / Equidistant, Energy Direction / Azimuthal). Emphasize that a map can be Conformal or Equivalent, but never both.

2. Live Demonstration Instructions (0:15 - 0:25)

  • Launch ArcGIS Pro with an empty map. Note that the default coordinate system is Web Mercator (Auxiliary Sphere), which preserves angles but distorts area away from the equator.
  • Right-click Map -> Properties -> Coordinate Systems to show the active spatial reference environment.

3. Student Supervision & Troubleshooting Guidelines (0:25 - 0:55)

Common Bottleneck: Students may confuse Projecting on-the-fly (changing map view settings) with using the actual Project Geoprocessing Tool (creating a new data file with recalculated coordinates). Walk around the lab to ensure students run the Project tool for spatial operations that require accurate distance measurements.

4. Wrap-up & Conceptual Review Questions (0:55 - 1:00)

Question: If you are calculating total acreage for a wildlife conservation zone, what family of map projection must you use?
Answer: An Equal-Area (Equivalent) projection, such as the Albers Equal Area Conic.

PART B: STUDENT HANDOUT & EXERCISE GUIDE

1. Core Principles to Retain

  • Horizontal Datums: Define (x,y) positioning across the surface (e.g., NAD83 for North America, WGS84 for global satellite positioning).
  • Vertical Datums: Define (z) heights relative to a tidal or gravimetric baseline (e.g., NAVD88).
  • Tissot's Indicatrix: A mathematical visualization method using small circles placed across a map grid to evaluate local scale distortion. On conformal maps, circles remain round but change in size; on equivalent maps, they stretch into ellipses but retain their original relative area.

2. Hands-on Click-Stream Exercise

  1. Open ArcGIS Pro and create a blank project named Workshop1_Geodesy.
  2. In the Catalog Pane, expand your workspace folder, right-click, and select New -> Shapefile. Set the name to Study_Area_Unprojected and assign it a Geographic Coordinate System (GCS_WGS_1984).
  3. Add a text layer or reference boundary to your map. Notice how northern regions appear disproportionately large due to Web Mercator distortion.
  4. Open the Geoprocessing Pane (Analysis tab -> Tools). Search for and open the Project tool.
  5. Set parameters: Input: Study_Area_Unprojected | Output: Study_Area_Projected_UTM | Output Coordinate System: Select NAD 1983 UTM Zone 18N.
  6. Click Run. Right-click the new layer, check its source properties, and observe the linear unit shift from decimal degrees to meters.

Workshop 2: Geospatial Data Models and Structural Topology

GISCI Alignment: Category 3: Data Modeling (12%) & Category 4: Geospatial Data (11%)
Software Environment: ArcGIS Pro (3.x)

PART A: TEACHER'S MASTER INSTRUCTION GUIDE

1. Conceptual Whiteboard Script (0:00 - 0:15)

Draw a 4x4 raster grid next to a vector polygon on the board. Contrast discrete vector features (explicit coordinate boundaries) with continuous raster models (a uniform grid of grid cells, where each cell contains a single value representing a phenomena like elevation or temperature).

Write down the three foundational tenets of spatial topology:
  • Adjacency: Which polygons share borders?
  • Containment: Which features lie inside another feature's boundary?
  • Connectivity: How are arcs or line lines linked at intersections?
Explain that topology is mathematical and does not change even if the map is stretched or projected.

2. Live Demonstration Instructions (0:15 - 0:25)

  • Open an active file geodatabase (.gdb).
  • Right-click the geodatabase, choose New -> Feature Dataset (explain that a feature dataset is required to build a topology network). Create a topology rule like "Must Not Overlap" to show how ArcGIS identifies structural spatial errors.

3. Student Supervision & Troubleshooting Guidelines (0:25 - 0:55)

Watch for students editing features without enabling topology validation. Remind them to click the Validate button in the Edit tab to see if any topology rules were broken.

4. Wrap-up & Conceptual Review Questions (0:55 - 1:00)

Question: If a line dataset representing a stream network contains lines that cross without a node, or dead-end short of their target, what topological errors have occurred?
Answer: Overshoots and undershoots (dangling nodes).

PART B: STUDENT HANDOUT & EXERCISE GUIDE

1. Core Principles to Retain

  • RDBMS: Store geospatial attribute tables. Tabular joins require a Primary Key in the destination table and a Foreign Key in the source table.
  • Cardinality: Defines relationship configurations between datasets:
    • One-to-One (1:1): One parcel record matches one address.
    • One-to-Many (1:M): One state contains many counties (requires a Relate or Relationship Class rather than a standard Join).

2. Hands-on Click-Stream Exercise

  1. Create a project named Workshop2_Topology.
  2. Right-click your GDB, choose New -> Feature Dataset, and name it Infrastructure. Set its coordinate reference system to your local UTM zone.
  3. Import your administrative boundary shapefiles into this dataset.
  4. Right-click Infrastructure, select New -> Topology. Name it Boundary_Topology.
  5. Add your administrative polygon layer, click Next, and click Add Rule. Select Must Not Have Gaps. Add a second rule for Must Not Overlap. Click Finish.
  6. Add the topology layer to your map, click the Edit tab, open the Error Inspector, and click Validate Full Extent to view geometric errors highlighted in red.

Workshop 3: Cartography, Symbology, and Quantitative Classification

GISCI Alignment: Category 5: Cartography & Visualization (10% Weight)
Software Environment: ArcGIS Pro (3.x)

PART A: TEACHER'S MASTER INSTRUCTION GUIDE

1. Conceptual Whiteboard Script (0:00 - 0:15)

Draw a simple number line containing clustered data points. Use this to illustrate three major classification styles:
  • Equal Interval: Divides the range of attribute values into equal-sized sub-ranges. (Show how this ignores data clusters).
  • Quantile: Places an equal number of features into each class category. (Show how this can place very different values in the same class).
  • Natural Breaks (Jenks): Minimizes variance within classes while maximizing variance between classes by finding natural groupings in the data.

2. Live Demonstration Instructions (0:15 - 0:25)

  • Add a population density polygon layer to a map layout.
  • Open the Symbology Pane and switch between Equal Interval, Quantile, and Jenks Natural Breaks. Point out how the visual narrative of the map changes drastically based on the classification method chosen.

3. Student Supervision & Troubleshooting Guidelines (0:25 - 0:55)

Key Concept: Remind students that raw counts (e.g., total population) should not be mapped using choropleth symbolization without first normalizing the data (e.g., dividing by square miles to map population density). Otherwise, larger geographic areas will look artificially prominent.

4. Wrap-up & Conceptual Review Questions (0:55 - 1:00)

Question: Which classification method should you use if you want to group data so that every map class contains the exact same number of counties?
Answer: Quantile Classification.

PART B: STUDENT HANDOUT & EXERCISE GUIDE

1. Core Principles to Retain

  • Visual Variables (Jacques Bertin): Shape, size, orientation, color hue, color value (lightness), color saturation, and texture. Hue is best for qualitative data (e.g., soil types); value and size are best for quantitative data (e.g., population rates).
  • Map Generalization Operations:
    • Simplification: Removing vertex density from complex lines.
    • Aggregation: Combining separate adjacent bodies into a single feature.
    • Displacement: Purposely shifting features apart so they remain visible at smaller display scales.

2. Hands-on Click-Stream Exercise

  1. Open a project containing demographic polygon data. Right-click the layer and select Symbology.
  2. In the Symbology pane, change the Primary Symbology dropdown to Graduated Colors.
  3. Set the Field property to your raw population variable (e.g., POP_2026). Note the normalization warning.
  4. Set the Normalization dropdown option to your area field (e.g., SQ_MILES).
  5. Change the Method dropdown to Natural Breaks (Jenks) and set the class count to 5. Examine the distribution histogram, then switch to Quantile to observe the spatial distortion shift.

Workshop 4: Remote Sensing, Image Processing, and Pixels

GISCI Alignment: Category 6: Platforms, Sensors, Principles (10% Weight)
Software Environment: ArcGIS Pro (3.x)

PART A: TEACHER'S MASTER INSTRUCTION GUIDE

1. Conceptual Whiteboard Script (0:00 - 0:15)

Draw the electromagnetic spectrum on the whiteboard. Label Ultraviolet, Visible (Blue, Green, Red), Near-Infrared (NIR), Shortwave Infrared (SWIR), and Thermal Infrared.

Explain the four types of resolution that define any sensor platform:
  • Spatial Resolution: Pixel size grid dimensions (e.g., 30m Landsat vs. 10m Sentinel).
  • Spectral Resolution: The number of fine wavelength bands captured by the sensor.
  • Radiometric Resolution: The bit-depth storing data per pixel (e.g., 8-bit = 256 levels; 16-bit = 65,536 levels).
  • Temporal Resolution: The revisit frequency cycle of the satellite platform over a given spot.

2. Live Demonstration Instructions (0:15 - 0:25)

  • Load a composite multispectral image layer.
  • Open the Symbology Pane to demonstrate band reassignment. Change the band combination from True Color to False Color Infrared (Red=NIR, Green=Red, Blue=Green), showing how healthy vegetation reflects strongly in the near-infrared band and appears bright red.

3. Student Supervision & Troubleshooting Guidelines (0:25 - 0:55)

Ensure students select the correct input bands when using the Raster Calculator to calculate NDVI. The formula is strictly:

NDVI = (NIR - Red) / (NIR + Red)

4. Wrap-up & Conceptual Review Questions (0:55 - 1:00)

Question: Why does healthy vegetation appear bright red in a traditional False-Color Infrared satellite image composite?
Answer: The Near-Infrared band is mapped to the red display channel, and healthy plant leaves reflect highly in the NIR spectrum due to their internal spongy mesophyll structure.

PART B: STUDENT HANDOUT & EXERCISE GUIDE

1. Core Principles to Retain

  • Active vs. Passive Sensors: Passive sensors collect naturally reflected solar energy (e.g., Landsat). Active sensors generate their own energy pulse and measure the return echo bounce (e.g., LiDAR, RADAR).
  • Image Classification:
    • Supervised: The user draws training samples over known cover types to train the classification algorithm.
    • Unsupervised: The software groups pixels into clusters based on statistical spectral similarities without user input.

2. Hands-on Click-Stream Exercise

  1. Create a project named Workshop4_RemoteSensing and import a multispectral scene layer.
  2. Select your image layer in the Contents pane, and click the Imagery context tab on the main ribbon.
  3. Click the Raster Functions button. Expand the Math category and select NDVI.
  4. Set the parameters: Visible Band = Red channel (Band 4 for Landsat 8) | Infrared Band = Near-Infrared channel (Band 5 for Landsat 8).
  5. Check the box for Scientific Output (scales values strictly between -1.0 and +1.0) and click Create New Layer. Review your output canopy maps.

Workshop 5: Vector Analysis, Geoprocessing, and Spatial Statistics

GISCI Alignment: Category 1: Analytical Methods & GeoComputation (18% Weight)
Software Environment: ArcGIS Pro (3.x)

PART A: TEACHER'S MASTER INSTRUCTION GUIDE

1. Conceptual Whiteboard Script (0:00 - 0:15)

Draw two overlapping circle features on the board (A and B). Use them to illustrate the mathematical difference between vector overlay tools:
  • Intersect: Keeps only the areas where features overlap (A ∩ B). Attributes from both layers are combined.
  • Union: Keeps all areas from both layers (A ∪ B), combining them into a new output feature class.
  • Clip (Cookie-Cutter): Cuts out a piece of one layer using the boundary of another. Features are clipped, but no attributes from the clipping layer are transferred.

2. Live Demonstration Instructions (0:15 - 0:25)

  • Open the Geoprocessing Search Tab and demonstrate how to search for analytical tools.
  • Run a spatial query using Select Layer By Location to select features within a certain distance of another layer. Show how this creates a selection highlight without creating a new file on disk.

3. Student Supervision & Troubleshooting Guidelines (0:25 - 0:55)

Make sure students understand that Clip and Intersect do different things with attribute tables. Intersect combines attributes from both tables, while Clip only keeps attributes from the input layer.

4. Wrap-up & Conceptual Review Questions (0:55 - 1:00)

Question: If you combine an environmental risk zone layer with a property parcel layer, and you want an output that includes all geometry and attributes from both layers, which geoprocessing tool should you run?
Answer: The Union tool.

PART B: STUDENT HANDOUT & EXERCISE GUIDE

1. Core Principles to Retain

  • First Law of Geography (Tobler): "Everything is related to everything else, but near things are more related than distant things." This principle forms the foundation for spatial autocorrelation and interpolation.
  • Spatial Autocorrelation (Moran's I): Measures how clustered or dispersed data is across an area. Positive values indicate clustering; negative values indicate dispersion.
  • Spatial Interpolation: Estimates unknown values at unsampled locations using measurements from surrounding sample points (e.g., IDW, Kriging).

2. Hands-on Click-Stream Exercise

  1. Open a map project containing point data for water quality sample locations. Open the Geoprocessing pane.
  2. Search for and open the Buffer tool. Set sample points as input, name the output Samples_100m_Buffer, and set the distance to 100 Meters. Click Run.
  3. Search for the Intersect tool in the Geoprocessing pane.
  4. Set parameters: Input Features: Select your new buffer layer and a land-use zoning polygon layer | Output Feature Class: Zoning_Buffer_Intersection.
  5. Click Run. Open the attribute table of your new output layer to confirm it contains fields from both input tables.

Workshop 6: Distributed Web GIS, Cloud Architectures, and Ethics

GISCI Alignment: Web-Based GIS (2%), Systems Design (8%), GI & Society (3%)
Software Environment: ArcGIS Online Ecosystem

PART A: TEACHER'S MASTER INSTRUCTION GUIDE

1. Conceptual Whiteboard Script (0:00 - 0:15)

Sketch a classic Three-Tier Enterprise GIS Architecture on the board:
Client Tier: Web browsers, mobile apps, desktop GIS software.
Server Tier: Application servers that handle web data processes (e.g., ArcGIS Server).
Data Tier: Enterprise relational databases (e.g., PostgreSQL, SQL Server).

Write down the open web service standards developed by the Open Geospatial Consortium (OGC):
  • WMS (Web Map Service): Returns static, pre-rendered map images.
  • WFS (Web Feature Service): Returns actual vector feature geometries and editable attributes.
  • WCS (Web Coverage Service): Returns raw, uncompressed raster cell values (e.g., DEM elevation pixels).

2. Live Demonstration Instructions (0:15 - 0:25)

  • Log in to your institutional ArcGIS Online portal account.
  • Share a map layer from ArcGIS Pro up to your portal. Explain the difference between sharing data as a flat, pre-rendered Tile Layer versus an interactive, queryable Hosted Feature Layer.

3. Student Supervision & Troubleshooting Guidelines (0:25 - 0:55)

Help students configure sharing permissions correctly. Ensure they understand that keeping an item set to Owner or Organization restricts access, while setting it to Public allows anyone on the internet to view and query the service.

4. Wrap-up & Conceptual Review Questions (0:55 - 1:00)

Question: If a government agency needs to share geographic boundaries over the web so that users can download the raw vector geometry and edit attribute values locally, which web service standard should they use?
Answer: An OGC-compliant Web Feature Service (WFS).

PART B: STUDENT HANDOUT & EXERCISE GUIDE

1. Core Principles to Retain

  • RESTful APIs: Allow web maps to communicate with servers using standardized URLs.
  • GISCI Code of Ethics Principles:
    • Duty to Society: Provide accurate data, respect privacy, and do not use spatial data to discriminate against groups of people.
    • Duty to Employers/Clients: Disclose any conflicts of interest and acknowledge data limitations or uncertainties.

2. Hands-on Click-Stream Exercise

  1. Open your workspace project in ArcGIS Pro. Ensure you are signed into your Bucknell organizational account.
  2. In the Share ribbon tab, click Web Layer -> Publish Web Layer.
  3. In the configuration window, name it: Bucknell_Campus_Resources_YourInitials | Layer Type: Select Feature.
  4. Under the Configuration tab, ensure the operations are limited to Query only.
  5. Click Analyze to check for errors. If clean, click Publish. Log into your ArcGIS Online browser account to confirm the layer works in Map Viewer.
