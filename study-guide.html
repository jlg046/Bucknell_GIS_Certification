Pathway 4: High-Yield Study Guide

This high-yield outline is designed for students to review before taking mock exams.

Domain 1: Analytical Methods & GeoComputation 18%

  • Spatial Autocorrelation: Evaluates how features are clustered, dispersed, or random across space. Know the difference between global metrics (Moran’s $I$) and local metrics (Anselin Local Moran’s $I$, Getis-Ord $Gi^*$).
  • Interpolation: Predicting values at unsampled locations. Know the differences between deterministic models (IDW, Splines) and geostatistical models (Kriging, which accounts for spatial autocorrelation and yields error variances).
  • Overlay Analysis: Vector overlay combines geometries and attributes (Intersection is an "AND" relationship; Union is an "OR" relationship). Raster overlay requires matching grid resolution, alignment (snapping), and standardized scales (Weighted Linear Combination).

Domain 2: Conceptual Foundations 14%

  • Datums: Define the origin point and orientation of coordinate systems. Understand the difference between local datums (NAD27, optimized for North America) and geocentric/global datums (WGS84, NAD83, centered at the Earth's mass center).
  • Projections: Flattening the 3D ellipsoid onto a 2D plane. No flat projection can maintain all properties. Remember the trade-offs:
    • Conformal (e.g., Mercator): Preserves local angles and shapes; distorts size.
    • Equivalent/Equal-Area (e.g., Albers Equal Area): Preserves area/size; distorts shape and angles.
    • Equidistant: Preserves true distance along specific lines.
    • Azimuthal: Preserves direction from a central point.
  • Ellipsoid vs. Geoid: The ellipsoid is a smooth, mathematically simplified 3D representation of Earth's shape. The geoid represents the irregular surface of constant gravitational potential (approximately mean sea level).

Domain 3: Data Modeling 12%

  • Data Models: Vectors represent discrete objects using coordinates ($x, y$). Rasters represent continuous surfaces using regular grid cells.
  • Database Normalization: Process of structuring a relational database to reduce data redundancy and improve data integrity.
    • 1NF: Eliminate repeating groups; ensure atomic (indivisible) values.
    • 2NF: Meet 1NF and ensure all non-key attributes are fully functionally dependent on the primary key (no partial dependencies).
    • 3NF: Meet 2NF and ensure non-key attributes do not depend transitively on other non-key attributes.
  • Spatial Indexing: Acceleration structures for spatial queries (e.g., R-Tree, which groups objects using minimum bounding rectangles, or Quadtrees, which recursively partition spaces into quadrants).

Domain 4: Geospatial Data 11%

  • Metadata: Structured data about data. Standards include FGDC (US Federal Geographic Data Committee) and ISO 19115 (Geographic Information - Metadata).
  • Open Formats: GeoJSON (JSON-based, text format for web), GeoPackage (SQLite-based database format), and Shapefile (older multi-file format with a 2GB size limitation and 10-character field limit).
  • Data Quality: Accurate data is close to the true value. Precise data is highly detailed or consistent. Logical consistency checks if spatial relationships within the dataset make topological sense (e.g., polygons do not overlap if they represent parcel boundaries).

Domain 5: Cartography & Visualization 10%

  • Visual Variables: The properties of a map symbol that dictate how it is interpreted (size represents quantitative data, shape represents qualitative/categorical data, color hue represents categories, and color value/saturation represents order or quantities).
  • Data Classification:
    • Natural Breaks (Jenks): Sets boundaries where there are natural groupings and gaps in the data values.
    • Quantile: Assigns an equal number of features to each class; hides outliers but can overstate variations.
    • Equal Interval: Divides the range of attribute values into equal-sized sub-ranges.
    • Standard Deviation: Shows how much a feature's attribute value varies from the mean.

Domain 6: Platforms, Sensors, Physical Principles, Image Processing & Analysis 10%

  • Resolutions:
    • Spatial: Grid cell size representing the ground surface (e.g., 30m vs. 1m).
    • Spectral: The number and width of electromagnetic bands recorded.
    • Temporal: Revisit time of the sensor over the same spot on Earth.
    • Radiometric: Bit depth of the sensor (e.g., 8-bit can represent 256 gray values; 16-bit can represent 65,536).
  • Active vs. Passive Sensors: Active sensors emit their own electromagnetic energy to illuminate the target (LiDAR, Radar). Passive sensors record naturally occurring energy reflected or emitted from the Earth (Landsat, Sentinel multispectral).
  • NDVI: Normalized Difference Vegetation Index. Highly reflective in NIR (Near-Infrared) and highly absorptive in Red bands due to chlorophyll.
$$NDVI = \frac{NIR - Red}{NIR + Red}$$

Domain 7: Design of Systems 8%

  • Enterprise Architecture: Multi-tier systems typically consisting of:
    • Data Tier (Database): Spatial RDBMS (e.g., PostgreSQL/PostGIS) managing geometries and attributes.
    • Application Tier (Server): Processes spatial logic and serves map data as web resources.
    • Presentation Tier (Client): Desktop GIS, web browsers, or mobile apps displaying the map and running UI interactions.
  • OGC Standards: Open Geospatial Consortium standards facilitate interoperability:
    • WMS (Web Map Service): Returns georeferenced map images (PNG, JPG).
    • WFS (Web Feature Service): Returns actual vector geometries and attributes (XML/GML, JSON).
    • WCS (Web Coverage Service): Returns multidimensional grid raster data (GeoTIFF, NetCDF).

Domain 8: Organizational & Institutional Aspects 7%

  • Project Management: Adapting project management structures (like the System Development Life Cycle or Agile methodologies) specifically to geospatial databases, ensuring quality assurance (QA) and quality control (QC).
  • Ethics: The GISCI Code of Ethics dictates professional behavior, including honesty to the public, integrity in presenting data limitations, and securing data privacy.

Domain 9: Thematic & Application Domains 5%

  • Understand spatial analytical use cases across urban planning (zoning, suitability), conservation (watershed delineation, habitat connectivity), public health (epidemiology clustering), and business (geomarketing, gravity models).

Domain 10: GI & Society 3%

  • Privacy: The rise of GPS tracking, location-based services (LBS), and high-resolution imagery raises significant concerns around location privacy. Understand techniques like geomasking and anonymization.
  • Participatory GIS (PGIS): Incorporating community knowledge and public participation into geographic decision-making to address environmental justice and community needs.

Domain 11: Web-Based GIS 2%

  • Architecture: Relying on client-server protocols. Clients query databases via REST (Representational State Transfer) APIs.
  • Web Tiles:
    • Raster Tiles: Pre-rendered map images stored on the server; faster rendering but static design.
    • Vector Tiles: Vector data packaged into standardized chunks and sent to the client, which handles the cartographic styling dynamically.
